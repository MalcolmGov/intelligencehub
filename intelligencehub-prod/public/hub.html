        // SDLC 2.0

        AI in Every Phase of the SDLC

        Embedding Claude (via Microsoft AI Foundry) across the seven phases of how we build software — accelerating delivery, improving quality, reducing cost, strengthening security & governance.

        1
        Plan & Requirements
        Define objectives, gather requirements, prioritise backlog.
        AI — DiscoverySummarise source material; extract requirements from docs & emails; identify gaps; prioritise with data insights.
        2
        Design
        Solution architecture, data models, API specs, UI/UX.
        AI — AssistGenerate architecture options; draft data models, API contracts & wireframes; flag pattern deviations.
        3
        Development
        Write code, integrate components, follow standards, unit test.
        AI — AugmentInline completion; generate functions, classes & APIs; refactor; explain code; convert requirements to code.
        4
        Testing
        Test functionality, performance, security, usability.
        AI — EnhanceGenerate test cases from stories; create test data & mocks; draft automation; summarise results.
        5
        Deployment
        Release to staging / production, manage configs, migrations.
        AI — AssistGenerate deploy scripts; validate IaC; predict deployment risk; auto-draft release notes & rollback plans.
        6
        Operations & Monitoring
        Monitor systems, logs, performance, incidents, alerts.
        AI — OperateAnomaly detection & alert correlation; root-cause hypotheses; log summarisation; auto-generate runbooks.
        7
        Maintenance & Evolution
        Fix defects, improve features, refactor, continuously evolve.
        AI — EvolveSynthesise feedback themes; suggest features & refactors; impact analysis on proposed changes.
