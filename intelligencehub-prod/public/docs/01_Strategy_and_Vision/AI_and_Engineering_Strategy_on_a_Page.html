Copilot vs Claude Code · same metrics · same cohort

Copilot-primary Option A

Better cost-per-accepted-change and engineer preference. Claude retained for narrow expert cohort on long-horizon refactors.

Claude-primary Option B

Wins on task completion, time-to-done, preference. Copilot retained for inline completion & Code Review flows.

Dual-use Most likely

Copilot for inline + Code Review + Chat. Claude Code for agentic multi-file changes, migrations, deep refactors.

Stop one track Safety

One tool fails safety, IP or adoption thresholds. De-scope; the other proceeds to Wave 2 alone.

Guardrails in every path

  • Prompts & outputs not used to train foundation models (contractual)
  • Public-code match filter ON · IP indemnification
  • Content exclusions on payments, fraud, secrets repos
  • Agentic execution confined to Dev Box / Codespaces
  • No production credentials in any agent context

Approvals before seat #1

  • DPIA signed by DPO (POPIA / NDPA / KDPA as applicable)
  • CISO sign-off on monitoring & agentic threat model
  • Legal: AUP & contract addendum
  • CRO: model-risk registration
  • Procurement: MACC drawdown & cost alerts

What the board sees quarterly

  • DORA: lead time · deploy freq · change-fail · MTTR
  • Adoption: seats active · accept rate · cohort coverage
  • Value: time saved · cost per accepted change
  • Safety: secret-scan regressions · CodeQL trend · incidents
  • Governance: use-cases in register · audit findings closed
