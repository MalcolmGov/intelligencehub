🔀LangGraph StateGraph · agent/graph.py
📋
planner
Entry point. Receives translated intent, builds ordered step plan, sets OrchestrationState.
⚙️
tool_executor
Executes current step via ServiceRegistry. Conditional edge routes to one of four outcomes:
→ approve → execute → rollback → done
🔐
approval_gate
Pauses graph. Awaits human decision. Approved → loops back to tool_executor. Rejected → responder.
↩️
rollback
Reverses completed steps in inverse order when a step fails. Passes to responder on completion.
📤
responder
Terminal node. Assembles final response from OrchestrationState. Appends to audit log → END.
🔍NLTranslator · 7-Step Pipeline · agent/nl_translator.py
1
Classify orchestration type
Keyword scoring → QUERY / MUTATION / WORKFLOW / DIAGNOSTIC. No LLM.
2
Extract action verb
Matches against _VERB_MAP (35 canonical verbs). Falls back to first content word.
3
Fuzzy service matching
difflib sequence matching against all 8 registered service IDs. Threshold ≥ 0.6.
4
Extract parameters
Regex patterns for amounts, ISO dates, account numbers embedded in the command.
5
Determine environment
Keyword detection: "staging" → staging, otherwise production. Affects approval rules.
6
Determine approval requirement
Triggers on destructive verb OR MUTATION to production. Two-layer: NL-level + tool-level.
7
Compute confidence score
Starts 1.0. Penalties: −0.2 no services, −0.1 UNKNOWN type, −0.1 no params extracted.
Human-in-the-Loop (HITL) · Two Approval Layers
Layer 1 — NL-level
Triggered by destructive verb (delete, freeze, rollback, cancel…) or a MUTATION to production detected during parsing. Set in NLTranslator._determine_approval().
Layer 2 — Tool-level
Triggered per capability in ServiceRegistry where requires_approval=True. Checked inside tool_executor for every planned step, independently of Layer 1.
On approval: approval_gate → tool_executor — graph loops back to continue the next planned step.
On rejection: approval_gate → responder — execution halts, partial state is preserved in the audit log, no rollback initiated.
