⚠ POPIA Consent Ledger

POPIA Compliance Critical. This entity cluster implements South Africa's Protection of Personal Information Act (POPIA) requirements. All consent records are immutable and append-only. Withdrawal of consent does not delete records — it creates a withdrawnAt entry. Erasure requests trigger workflows across all affectedSystems.
consents[] — Schema
FieldTypeNullableDescriptionPOPIA
purposestringNOSpecific processing purpose (e.g. "marketing_email", "credit_risk_profiling", "ai_personalisation")Non-PII
grantedbooleanNOCurrent consent state. Must be re-evaluated if expiresAt has passed.Non-PII
grantedAtDateTimeNOTimestamp of original consent grantNon-PII
expiresAtDateTimeYESOptional consent expiry. Null = indefinite. System must re-prompt on expiry.Non-PII
channelstringNOChannel through which consent was captured: web | mobile | branch | ivr | emailNon-PII
ipAddressstring (hashed)YESSHA-256 hashed IP address for digital consent recordsPII
versionstringNOVersion of the consent notice/wording presented to customer at time of grantNon-PII
withdrawnAtDateTimeYESTimestamp of consent withdrawal. Null if consent still active. Record is never deleted.Non-PII
