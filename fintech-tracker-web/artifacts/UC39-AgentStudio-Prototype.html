What is an Agent?
An agent is an AI that can take autonomous actions on your behalf — not just answer questions, but actually do things: query your databases, send Slack messages, block fraud transactions, create ServiceNow tickets, and write reports.

Unlike a chatbot, an agent runs in the background 24/7, triggered by events (like a PagerDuty alert or a new transaction), works through a sequence of tool calls, and only asks for your approval when the action is high-risk or irreversible.

You stay in control: every agent has approval gates — guardrails that pause the agent and ask you before any consequential action executes.
Frequently Asked Questions
Do I need to write code?▾
No. The wizard guides you through every step. System prompts use plain English. Tools connect via pre-built integrations. You only write code if you want to build a custom tool connector.
What happens if the agent makes a mistake?▾
Every consequential action is behind an approval gate — the agent pauses and waits for your sign-off before executing. You can also pause or roll back any agent at any time from the My Agents panel.
Which AI models are available?▾
Claude Opus 4 (most powerful, for complex reasoning), Claude Sonnet 4 (best balance of speed and quality), and Claude Haiku 4 (fastest and cheapest, for high-volume tasks like transaction screening).
How much does it cost?▾
Costs vary by model and run volume. The platform dashboard shows real-time cost tracking per agent. Typical agents cost between R 18–R 310 per day. Budget alerts can be configured per agent.
Is my data secure?▾
Yes. All data stays within MTN's private cloud. API calls are encrypted in transit. PII is masked in logs. The platform is POPIA-compliant and every action is recorded in the immutable audit log.
Key Concepts at a Glance
🧠
System Prompt
Plain-English instructions that define your agent's personality, goals and constraints. Think of it as a job description for your AI.
🔧
Tool Connections
Integrations that let the agent take real actions — query Prometheus, post to Slack, block a bank account, create a ServiceNow ticket.
🚦
Approval Gates
Rules that pause the agent before risky actions and notify a human approver. Your safety net — fully configurable per action type.
⚡
Triggers
What activates the agent: a webhook (e.g. PagerDuty alert), a schedule (e.g. every Monday 08:00), or a manual click.
🔁
Pipeline / Workflow
The sequence of steps the agent follows: receive trigger → gather data → reason → decide → act. Visible in real time in each agent's panel.
📜
Audit Log
Every agent action is recorded with timestamp, inputs, outputs and who approved it. Immutable and exportable for compliance.
