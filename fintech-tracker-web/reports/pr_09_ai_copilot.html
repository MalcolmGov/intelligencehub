5. Production Requirements

Compute Resources

RAG Engine Service

CPU: 8 vCPU (base), autoscale 6-16 vCPU

Memory: 16 GB (base), autoscale 12-32 GB

Rationale: High I/O for vector search + LLM latency; needs CPU for embedding calculations

Pinecone Vector Store

Tier: Pro (production-grade SLA)

Vectors: 50,000+ embeddings with metadata

Rationale: Serverless managed service; scales automatically with query load

Storage

  • PostgreSQL: 200 GB (interaction logs, conversation history); daily backups with 30-day retention
  • Vector embeddings: ~2 GB in Pinecone (15,000 test cases + 50,000 failure logs)
  • Cache (Redis): 20 GB (recent embeddings, conversation caches); 1-hour TTL

Network & Security

  • VPC: Private subnet with NAT gateway for outbound API calls to OpenAI, Pinecone
  • Security Groups: Allow inbound 443 (HTTPS) from QA network; restrict egress to known API endpoints
  • TLS: All APIs enforced with TLS 1.3; certificate auto-renewal via cert-manager
  • Rate Limiting: OpenAI: 100 req/min, 3,500 tokens/min; Pinecone: 10,000 req/sec
  • Authentication: Azure AD SSO for user identity; service-to-service via mTLS + JWT

Secrets Management

Secret Storage Rotation Access
OpenAI API Key Azure Keyvault Monthly RAG pods only (Workload Identity)
Pinecone API Key Azure Keyvault Quarterly RAG pods (Workload Identity)
GitHub PAT Azure Keyvault Quarterly Document ingestion service only
PostgreSQL Password Azure Keyvault Quarterly DB connection pool (TLS enforced)

Monitoring & Observability

  • Metrics: Prometheus scrape every 30s; track response latency, embedding search time, answer accuracy, token usage
  • Logs: ELK stack with 30-day retention; log all queries and answers for analytics
  • Tracing: Jaeger distributed tracing for request flows through RAG engine and vector DB
  • Alerts: PagerDuty trigger on >2s response latency p95, embedding search failures, API errors >1%
