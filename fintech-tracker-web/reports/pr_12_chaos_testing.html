Executive Summary

The Chaos Testing Agent is an AI-powered system that continuously injects controlled failures into the production environment to validate system resilience, detect hidden failure modes, and automatically trigger remediation. Using machine learning, the system learns from failure patterns, optimizes chaos experiments, and predicts optimal times to run tests with minimal customer impact. This transforms reactive incident response into proactive resilience engineering.

Current State: Manual chaos testing scheduled quarterly; reactive incident response; limited automation for recovery; no ML-driven optimization
Target State: Continuous AI-driven chaos experiments; automated discovery of failure modes; intelligent remediation with rollback; ML-optimized test scheduling
Key Value: 70% reduction in MTTR (Mean Time To Recovery); proactive identification of failures before customer impact; improved system resilience
Timeline: 50 days across 4 phases; production deployment with confidence by end of Phase 4

Technical Architecture

The Chaos Testing Agent comprises eight integrated components coordinating chaos injection, impact assessment, and automated remediation:

Core Components

1. Experiment Orchestrator - Plans and schedules chaos experiments based on ML optimization. Manages approval workflows. Controls experiment lifecycle from planning to rollback.

2. Chaos Injection Engine - Implements network faults (latency, packet loss, DNS failures), compute failures (CPU spike, memory leak), storage faults (disk full, I/O timeout), cascading failures across services.

3. Impact Assessment Service - Monitors real-time metrics during chaos. Calculates blast radius. Detects customer-facing impact via golden signals (latency, error rate, throughput, saturation).

4. Automated Remediation Engine - Executes predefined recovery actions: auto-rollback, circuit breaker activation, DNS failover, scale-up operations, health check bypasses.

5. Failure Pattern Learning - ML model learns from historical chaos results. Identifies which failures have highest impact. Optimizes experiment selection for maximum coverage.

6. Anomaly Detection Service - Uses isolation forests to detect unexpected system behavior during chaos. Flags novel failure modes requiring investigation.

7. Root Cause Analysis Engine - Correlates chaos events with system logs, metrics, and trace data. Identifies root causes of failures automatically.

8. Human-in-the-Loop Controller - Enforces approval policies, safeguards, and blast radius limits. Maintains audit trail of all chaos activities.

The system integrates with Prometheus/Datadog for metrics, Elasticsearch for log correlation, Kubernetes for container chaos injection via LitmusChaos operators, and PagerDuty for incident notifications.

Uses LitmusChaos operators for pod failures, node failures, network delays. Integrates with Kubernetes API for deployment rollback, replica scaling, drain/cordon operations.

  • Elasticsearch - Log storage and aggregation for RCA (root cause analysis)
  • Grafana - Dashboards for experiment results and failure analysis

CI/CD Pipeline Integration

Jenkins/GitHub Actions trigger scheduled chaos experiments. Test results published as artifacts. Pass/fail gates prevent deployments if critical resilience gaps discovered.

from typing import Dict, List
import subprocess
import json
from dataclasses import dataclass

@dataclass
class NetworkFault:
    service_name: str
    namespace: str
    latency_ms: int = 0
    packet_loss_percent: float = 0.0
    error_rate_percent: float = 0.0
    duration_seconds: int = 60

class ChaosInjectionEngine:
    def __init__(self, kubernetes_client):
        self.k8s = kubernetes_client
        self.litmus_namespace = "litmus"

    def inject_network_latency(self, fault: NetworkFault) -> str:
        """Inject network latency using LitmusChaos pod-network-latency"""
        chaos_manifest = {
            "apiVersion": "litmuschaos.io/v1alpha1",
            "kind": "ChaosEngine",
            "metadata": {
                "name": f"latency-{fault.service_name}",
                "namespace": fault.namespace
            },
            "spec": {
                "appinfo": {
                    "appns": fault.namespace,
                    "applabel": f"app={fault.service_name}"
                },
                "engineState": "active",
                "chaosServiceAccount": "litmus-admin",
                "experiments": [{
                    "name": "pod-network-latency",
                    "spec": {
                        "components": {
                            "env": [
                                {"name": "NETWORK_LATENCY", "value": str(fault.latency_ms)},
                                {"name": "TOTAL_CHAOS_DURATION", "value": str(fault.duration_seconds)},
                                {"name": "JITTER", "value": "50"}
                            ]
                        }
                    }
                }]
            }
        }

        return self._apply_manifest(chaos_manifest)

    def inject_packet_loss(self, fault: NetworkFault) -> str:
        """Inject packet loss using LitmusChaos pod-network-packet-loss"""
        chaos_manifest = {
            "apiVersion": "litmuschaos.io/v1alpha1",
            "kind": "ChaosEngine",
            "metadata": {
                "name": f"packet-loss-{fault.service_name}",
                "namespace": fault.namespace
            },
            "spec": {
                "appinfo": {
                    "appns": fault.namespace,
                    "applabel": f"app={fault.service_name}"
                },
                "experiments": [{
                    "name": "pod-network-packet-loss",
                    "spec": {
                        "components": {
                            "env": [
                                {"name": "PACKET_LOSS_PERCENTAGE",
                                 "value": str(fault.packet_loss_percent)},
                                {"name": "TOTAL_CHAOS_DURATION",
                                 "value": str(fault.duration_seconds)}
                            ]
                        }
                    }
                }]
            }
        }

        return self._apply_manifest(chaos_manifest)

    def inject_compute_failure(self, service: str, namespace: str,
                               cpu_percent: int = 80,
                               duration_seconds: int = 60) -> str:
        """Inject high CPU usage using stress-ng in pod"""
        chaos_manifest = {
            "apiVersion": "litmuschaos.io/v1alpha1",
            "kind": "ChaosEngine",
            "metadata": {
                "name": f"cpu-stress-{service}",
                "namespace": namespace
            },
            "spec": {
                "experiments": [{
                    "name": "pod-cpu-hog",
                    "spec": {
                        "components": {
                            "env": [
                                {"name": "CPU_CORES", "value": "2"},
                                {"name": "TOTAL_CHAOS_DURATION",
                                 "value": str(duration_seconds)},
                                {"name": "CHAOS_KILL_COMMAND",
                                 "value": "killall stress-ng"}
                            ]
                        }
                    }
                }]
            }
        }

        return self._apply_manifest(chaos_manifest)

    def _apply_manifest(self, manifest: Dict) -> str:
        """Apply Kubernetes manifest and return ChaosEngine name"""
        yaml_str = json.dumps(manifest)
        result = subprocess.run(
            ["kubectl", "apply", "-f", "-"],
            input=yaml_str,
            capture_output=True,
            text=True
        )

        if result.returncode != 0:
            raise Exception(f"Failed to apply chaos manifest: {result.stderr}")

        return manifest['metadata']['name']

from prometheus_client import prometheus_client as prom
import numpy as np
from dataclasses import dataclass

@dataclass
class MetricBaseline:
    p50_latency_ms: float
    p99_latency_ms: float
    error_rate_percent: float
    throughput_rps: float

class ImpactAssessmentService:
    def __init__(self, prometheus_client):
        self.prometheus = prometheus_client
        self.error_threshold = 0.1  # 0.1% error rate
        self.latency_threshold = 1.5  # 1.5x baseline

    def calculate_blast_radius(self, experiment_id: str,
                              duration_seconds: int) -> Dict:
        """Calculate percentage of traffic/customers affected"""

        # Fetch baseline metrics (pre-chaos period)
        baseline = self._get_baseline_metrics(duration_seconds * 2)

        # Fetch current metrics during chaos
        current = self._get_current_metrics()

        # Calculate deviations
        error_rate_change = (
            (current.error_rate_percent - baseline.error_rate_percent) /
            (baseline.error_rate_percent + 0.01)
        )

        latency_ratio = (
            current.p99_latency_ms / (baseline.p99_latency_ms + 1)
        )

        throughput_ratio = (
            current.throughput_rps / (baseline.throughput_rps + 1)
        )

        # Customer-facing impact detection
        has_customer_impact = (
            current.error_rate_percent > self.error_threshold or
            latency_ratio > self.latency_threshold
        )

        # Estimate blast radius as percentage of traffic affected
        blast_radius = min(100, max(
            error_rate_change * 100,
            (latency_ratio - 1) * 50,
            (1 - throughput_ratio) * 100
        ))

        return {
            "blast_radius_percent": blast_radius,
            "has_customer_impact": has_customer_impact,
            "error_rate_change_percent": error_rate_change * 100,
            "latency_ratio": latency_ratio,
            "throughput_ratio": throughput_ratio,
            "metrics": {
                "baseline": baseline.__dict__,
                "current": current.__dict__
            }
        }

    def _get_baseline_metrics(self, lookback_seconds: int) -> MetricBaseline:
        """Query Prometheus for pre-chaos baseline metrics"""
        queries = {
            'p50_latency': 'histogram_quantile(0.5, http_request_duration_ms)',
            'p99_latency': 'histogram_quantile(0.99, http_request_duration_ms)',
            'error_rate': 'rate(http_errors_total[5m])',
            'throughput': 'rate(http_requests_total[1m])'
        }

        # Execute Prometheus queries
        results = {}
        for name, query in queries.items():
            value = self.prometheus.query_range(
                query,
                start_time=f"-{lookback_seconds}s",
                step="30s"
            )
            results[name] = self._average_metric(value)

        return MetricBaseline(
            p50_latency_ms=results['p50_latency'],
            p99_latency_ms=results['p99_latency'],
            error_rate_percent=results['error_rate'],
            throughput_rps=results['throughput']
        )

    def _get_current_metrics(self) -> MetricBaseline:
        """Query Prometheus for current metrics during chaos"""
        # Similar to _get_baseline_metrics but for recent 5 minutes
        pass

    def _average_metric(self, time_series_data: List) -> float:
        """Calculate average of time series data points"""
        values = [point['value'] for point in time_series_data]
        return np.mean(values) if values else 0.0

from enum import Enum
import asyncio

class RemediationAction(Enum):
    ROLLBACK_DEPLOYMENT = "rollback_deployment"
    SCALE_UP_REPLICAS = "scale_up_replicas"
    CIRCUIT_BREAKER = "circuit_breaker"
    DNS_FAILOVER = "dns_failover"
    DRAIN_NODE = "drain_node"

class RemediationEngine:
    def __init__(self, k8s_client, prometheus_client):
        self.k8s = k8s_client
        self.prometheus = prometheus_client
        self.remediation_timeout = 30  # seconds

    async def auto_remediate(self, experiment_id: str,
                            impact_assessment: Dict) -> List[str]:
        """Automatically execute remediation if blast radius exceeded"""

        blast_radius = impact_assessment['blast_radius_percent']
        has_customer_impact = impact_assessment['has_customer_impact']

        executed_actions = []

        # Trigger remediation if customer impact detected
        if has_customer_impact and blast_radius > 5:
            # Step 1: Attempt automatic rollback
            rollback_success = await self._rollback_deployment(experiment_id)
            if rollback_success:
                executed_actions.append("deployment_rollback")
                return executed_actions  # Rollback successful, stop

            # Step 2: If rollback fails, scale up replicas
            scale_success = await self._scale_up_replicas(experiment_id)
            if scale_success:
                executed_actions.append("scale_up_replicas")

            # Step 3: Activate circuit breaker
            circuit_breaker_success = await self._activate_circuit_breaker(
                experiment_id
            )
            if circuit_breaker_success:
                executed_actions.append("circuit_breaker_activated")

            # Step 4: Attempt DNS failover if available
            failover_success = await self._dns_failover(experiment_id)
            if failover_success:
                executed_actions.append("dns_failover")

        return executed_actions

    async def _rollback_deployment(self, experiment_id: str) -> bool:
        """Rollback Kubernetes deployment to previous revision"""
        try:
            # Get experiment details
            experiment = self.db.get_experiment(experiment_id)
            service = experiment['target_service']
            namespace = experiment['target_namespace']

            # Get deployment rollout history
            revisions = self.k8s.get_deployment_revisions(
                service, namespace
            )

            if len(revisions) < 2:
                return False  # No previous revision

            previous_revision = revisions[-2]

            # Execute rollback
            result = self.k8s.rollout_undo(
                service,
                namespace,
                to_revision=previous_revision['revision']
            )

            if result['status'] == 'success':
                # Wait for rollback to complete
                await asyncio.sleep(5)

                # Verify rollback success via metrics
                return await self._verify_metric_recovery()

            return False

        except Exception as e:
            print(f"Rollback failed: {e}")
            return False

    async def _scale_up_replicas(self, experiment_id: str) -> bool:
        """Increase replica count for affected service"""
        try:
            experiment = self.db.get_experiment(experiment_id)
            current_replicas = experiment['current_replicas']

            # Scale to 1.5x current capacity
            new_replicas = int(current_replicas * 1.5)

            self.k8s.scale_deployment(
                experiment['target_service'],
                experiment['target_namespace'],
                replicas=new_replicas
            )

            # Wait for new pods to become ready
            await asyncio.sleep(10)

            # Verify capacity increase
            return await self._verify_throughput_increase()

        except Exception as e:
            print(f"Scale-up failed: {e}")
            return False

    async def _activate_circuit_breaker(self, experiment_id: str) -> bool:
        """Activate circuit breaker to shed excess traffic"""
        try:
            # Update Istio DestinationRule with circuit breaker policy
            circuit_breaker_config = {
                "maxConnections": 1000,
                "http": {
                    "http1MaxPendingRequests": 1000,
                    "maxRequestsPerConnection": 10,
                    "consecutiveErrors": 5,
                    "interval": "30s",
                    "baseEjectionTime": "30s"
                }
            }

            self.k8s.update_destination_rule(
                experiment_id,
                circuit_breaker_config
            )

            return True

        except Exception as e:
            print(f"Circuit breaker activation failed: {e}")
            return False

    async def _verify_metric_recovery(self) -> bool:
        """Verify metrics return to baseline after remediation"""
        baseline_error_rate = 0.01
        max_latency_ms = 100

        current_metrics = self.prometheus.query(
            'http_errors_total'
        )

        current_error_rate = current_metrics.get('value', 0)

        return current_error_rate <= baseline_error_rate

from sklearn.ensemble import GradientBoostingRegressor
from sklearn.preprocessing import StandardScaler
import numpy as np

class FailurePatternLearner:
    def __init__(self, postgresql_client):
        self.db = postgresql_client
        self.impact_predictor = GradientBoostingRegressor(
            n_estimators=100,
            learning_rate=0.1
        )
        self.scaler = StandardScaler()

    def learn_from_historical_experiments(self):
        """Train ML model on historical chaos experiment results"""

        # Load historical experiments from database
        experiments = self.db.query(
            """SELECT id, chaos_type, target_service, blast_radius_percent,
                      customer_impact, error_rate_change, latency_ratio
               FROM experiment_results WHERE status = 'completed'"""
        )

        if len(experiments) < 50:
            return False  # Not enough data

        # Feature engineering
        X = np.array([
            [
                self._chaos_type_to_int(exp['chaos_type']),
                self._service_to_embedding(exp['target_service']),
                exp.get('error_rate_change', 0),
                exp.get('latency_ratio', 1.0)
            ]
            for exp in experiments
        ])

        y = np.array([exp['blast_radius_percent'] for exp in experiments])

        # Scale features
        X_scaled = self.scaler.fit_transform(X)

        # Train model
        self.impact_predictor.fit(X_scaled, y)

        return True

    def predict_impact(self, chaos_type: str,
                      target_service: str) -> float:
        """Predict expected blast radius for proposed experiment"""

        features = np.array([[
            self._chaos_type_to_int(chaos_type),
            self._service_to_embedding(target_service),
            0.0,  # Baseline error rate change
            1.0   # Baseline latency ratio
        ]])

        features_scaled = self.scaler.transform(features)
        predicted_impact = self.impact_predictor.predict(features_scaled)[0]

        return max(0, min(100, predicted_impact))

    def optimize_experiment_schedule(self) -> List[Dict]:
        """Generate optimal experiment schedule minimizing customer impact"""

        # Load all planned experiments
        planned = self.db.query(
            "SELECT * FROM chaos_experiments WHERE status = 'scheduled'"
        )

        # Score each experiment by predicted impact
        scored = []
        for exp in planned:
            predicted_impact = self.predict_impact(
                exp['chaos_type'],
                exp['target_service']
            )

            # Calculate optimal time (low traffic hours: 2-4 AM)
            optimal_time = self._calculate_optimal_time(
                exp['target_service']
            )

            scored.append({
                'experiment_id': exp['id'],
                'predicted_impact': predicted_impact,
                'optimal_time': optimal_time,
                'priority': 1.0 / (predicted_impact + 1)  # Higher priority for lower impact
            })

        # Sort by priority (higher first)
        sorted_exps = sorted(scored, key=lambda x: x['priority'], reverse=True)

        return sorted_exps

    def _chaos_type_to_int(self, chaos_type: str) -> int:
        type_map = {
            'network': 0,
            'compute': 1,
            'storage': 2,
            'cascading': 3
        }
        return type_map.get(chaos_type, -1)

    def _service_to_embedding(self, service_name: str) -> float:
        """Convert service name to numeric embedding"""
        return hash(service_name) % 100 / 100.0

    def _calculate_optimal_time(self, service_name: str) -> str:
        """Calculate optimal time window for experiment (low traffic hours)"""
        # Query traffic patterns for service
        traffic_pattern = self.db.query(
            f"""SELECT hour, avg_traffic FROM traffic_patterns
               WHERE service = '{service_name}'"""
        )

        # Find hour with lowest traffic
        min_hour = min(traffic_pattern,
                       key=lambda x: x['avg_traffic'])['hour']

        return f"{min_hour:02d}:00"

class RootCauseAnalysisEngine:
    def __init__(self, elasticsearch_client, postgres_client):
        self.es = elasticsearch_client
        self.db = postgres_client

    def analyze_failure(self, experiment_id: str) -> Dict:
        """Automatically determine root cause of failure during chaos"""

        experiment = self.db.get_experiment(experiment_id)

        # Collect evidence from multiple sources
        logs = self._fetch_logs(experiment, duration_minutes=15)
        metrics = self._fetch_metrics(experiment, duration_minutes=15)
        traces = self._fetch_traces(experiment, duration_minutes=15)

        # Analyze evidence
        root_causes = []

        # Check for resource exhaustion
        if metrics['memory_percent'] > 90:
            root_causes.append({
                'cause': 'memory_exhaustion',
                'evidence': f"Memory usage peaked at {metrics['memory_percent']}%",
                'confidence': 0.95
            })

        # Check for service dependency failures
        failed_services = self._extract_failed_services(logs)
        for service in failed_services:
            root_causes.append({
                'cause': f'downstream_service_failure_{service}',
                'evidence': f"Service {service} returned errors during chaos",
                'confidence': 0.85
            })

        # Check for configuration issues
        config_changes = self._analyze_config_history(experiment)
        if config_changes:
            root_causes.append({
                'cause': 'configuration_mismatch',
                'evidence': f"Configuration changed: {config_changes}",
                'confidence': 0.70
            })

        # Sort by confidence
        root_causes.sort(key=lambda x: x['confidence'], reverse=True)

        return {
            'experiment_id': experiment_id,
            'root_causes': root_causes,
            'primary_cause': root_causes[0] if root_causes else None,
            'recommendations': self._generate_recommendations(root_causes)
        }

    def _fetch_logs(self, experiment: Dict, duration_minutes: int) -> List[str]:
        """Fetch application logs during chaos window"""
        query = {
            "bool": {
                "must": [
                    {"match": {"service": experiment['target_service']}},
                    {"range": {"timestamp": {
                        "gte": f"now-{duration_minutes}m"
                    }}}
                ]
            }
        }

        results = self.es.search(index="application-logs", body=query)
        return [hit['_source']['message'] for hit in results['hits']['hits']]

    def _extract_failed_services(self, logs: List[str]) -> List[str]:
        """Extract services that failed based on log analysis"""
        failed_services = set()

        for log_entry in logs:
            if "connection refused" in log_entry.lower():
                service = self._extract_service_name(log_entry)
                if service:
                    failed_services.add(service)

            if "timeout" in log_entry.lower():
                service = self._extract_service_name(log_entry)
                if service:
                    failed_services.add(service)

        return list(failed_services)

    def _generate_recommendations(self, root_causes: List[Dict]) -> List[str]:
        """Generate actionable recommendations based on root causes"""
        recommendations = []

        for cause in root_causes:
            if cause['cause'] == 'memory_exhaustion':
                recommendations.append(
                    "Increase memory limits for affected service"
                )
                recommendations.append(
                    "Implement memory-based auto-scaling (HPA)"
                )

            elif 'downstream_service_failure' in cause['cause']:
                service = cause['cause'].split('_')[-1]
                recommendations.append(
                    f"Implement circuit breaker for {service} calls"
                )
                recommendations.append(
                    f"Add retries with exponential backoff for {service}"
                )
